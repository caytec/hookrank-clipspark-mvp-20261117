Privacy

This Pages-compatible release is a browser demo. It does not upload selected video files to a processing service, store source media, transcribe audio, render clips, or create download files.

Files selected in demo mode

Your browser exposes the selected file to the page so the interface can validate its name, type, size, and optional local duration metadata. The demo does not send the file to a server. Closing or refreshing the page clears the page state.

Production processing

Production processing is not enabled in this release. Before a real upload workflow launches, ClipSpark must document its verified legal entity, processors, storage location, retention duration, deletion mechanism, security controls, user rights, and support contact.

Content rights

Only select content that you own or are authorized to process. Do not use this demo to submit confidential or sensitive media if your organization has not approved the workflow.

Contact

Privacy questions are not currently handled through a verified public support address. A verified contact will be published before production processing launches.
